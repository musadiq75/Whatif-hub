## Render sequence (the whole pipeline in 7 moves)

1. **Narration:** generate narration from `02-NARRATION-TTS.md` (per tooling in `05-TOOLING.md`), producing `audio/narration.wav`.
2. **Timestamps:** run WhisperX (or equivalent, per `05-TOOLING.md`) on the narration to produce word-level timestamps; regenerate `03-CAPTIONS.srt` timings from them (runbook step 4 gives the exact command).
3. **Footage:** generate 43 video clips using prompts in `01-SHOT-PROMPTS.md` via the video-gen tools in `05-TOOLING.md`; keyframe-first workflow from `06-ASSET-SPLIT.md`.
3a. **Stills** for any shot flagged `STILL` in `06-ASSET-SPLIT.md` can be generated by AshnaAI's image tool on request (unbranded outputs require a paid plan or an unbranded provider — see file).
3b. All footage must be re-timed to the actual narration timing table (runbook step 2), not the estimates.
4. **Assets:** collect music/SFX per `05-TOOLING.md` (YouTube Audio Library / Pixabay / Freesound CC0), drop into `audio/music/` and `audio/sfx/` named per the sound cue table in the production package §7.
5. **Assembly:** execute `04-ASSEMBLY-RUNBOOK.md` steps 1–6 in order, verifying after each stage (it includes the check commands).
6. **Export:** runbook step 7 renders the final 1920×1080 23.976fps H.264 MP4 at 12–16 Mbps.
7. **QC:** run the runbook §8 checklist; only then is Video 1 "finished."

## Key rules baked into every file

- Script 1 is LOCKED verbatim (production package §2). Nothing in this folder alters it.
- No watermarked assets in the final render. Stills from AshnaAI's image tool carry a free-tier watermark and are for layout/style reference only; final footage must come from unbranded sources.
- No slideshow: the runbook enforces motion in every shot (camera moves are specified per shot in `01-SHOT-PROMPTS.md`) and a minimum of ~6s per shot with cut-on-beat pacing.
- Scene 5's long-term visuals are explicitly labeled speculation on-screen; no invented statistics anywhere.
